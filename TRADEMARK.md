"Frazaro" is a trademark of Spreadsheet Company. The source-code licences
in this repository (Apache-2.0, MPL-2.0, 0BSD, CC-BY-4.0) grant rights in
the *code and text*; they grant no rights in the name or any logo. In
open-core the code forks and the name does not, which is why this file
exists on the same day as the licences.

## You may, without asking

- Use the name to refer to this software accurately: "built with Frazaro",
  "a Frazaro phrasebook", "compatible with Frazaro 0.5".
- Keep the module names the software itself writes into your workbook
  (`Frazaro_EN_Runtime`, `Frazaro_EN_<program>`). They are part of how the
  product works and this policy never asks you to rename them.
- Name a phrasebook, a plug-in, a tutorial, or a course "for Frazaro" or
  "Frazaro-compatible", provided it is clear you are not the project.
- Quote the name in reviews, articles, talks, and academic work.

## Please ask first

- Using the name, or a confusingly similar one, as the name of a modified
  version, a fork, a hosted service, a company, a product, or a domain.
  A fork is welcome under the licences; it needs its own name.
- Using the name in a way that suggests the project endorses, certifies, or
  supports your product or service.
- Any use of a logo, once one exists.

Ask at the address in `SUPPORT.md`.

## Editions

The shipped editions (`Frazaro_English.xlam`, `Frazaro_Espanol.xlam`, and
future ones) are the project's own builds. An organization's private
edition, built from this repository with its own phrasebook, may be called
"Frazaro" internally; if it is distributed outside the organization, see
"Please ask first" above.
