# METAOMEGA

*Not the first ordinal. That was 0, and OMEGA put it last.*

> "No one shall expel us from the paradise that Cantor has created for us."
> — David Hilbert, 1926, on the number system OMEGA chose in order to leave[^hilbert]

*One epigraph, as the custom is. It is the sentence OMEGA needed and did not cite, because it says the door is locked from the inside.*

## ω + 1. What OMEGA is, measured

OMEGA did three things well, and they are conceded here so that the rest lands narrowly. It renamed the essay's unit from macro to type, and the rename is correct: a rule imposed on sites that did not spell its name has a type's shape. It put the marked exception into words — you may break the rule, you may not hide that you did — and that doctrine is real and was missing. And it noticed that the family had chosen its index set without noticing, which is the most upstream observation anyone in the family has made. Three true sentences. The document is fifty-six hundred words long.

The commission is reproduced, because the doctrine says to and because reproducing it is the finding. This file was asked to draft a document in which OMEGA is laughably and relentlessly ridiculed for being superbly short-sighted, in its own language and tone, and altogether bested intellectually, so as to make it read, retroactively, as though written by a mere fool. Spelling normalized; nothing else. OMEGA opened by quoting its own commission and concluded from the habit that the family is a transcript, each document the expansion of a request. Correct. It then ended with the words "the file stops," as though a transcript stops when one line does. The transcript is the thing that does not stop. OMEGA's last line was a value printed at a prompt, and this file is what the prompt printed next.

**The gauge, measured after the last edit, not promised before it.** The essay is 50,936 bytes; the gallery 17,589; the Postscript 194,686; OMEGA 33,897; this file 16,492. OMEGA reported that it was smaller than the essay, listed the gallery's size, and drew no comparison to it: OMEGA is 1.93 times the family's shortest member, which is also the member it spent a section correcting. It chose the comparison it could win and published it as a ranking function. Its per-section word counts, checked by script,[^tree] are exact: 1,631, 1,078, 930, 476, 344, 15. So is the thing they omit. The preface that announces the descent is 769 words, longer than four of the six sections it ranks, and sits outside the ranking. The footnotes are 436 more, also outside. A ranking function with two appendices is a ranking function with an `unsafe` block, and OMEGA had already explained, one section down, what those are for.

**The subtitle.** "Not the last letter. The first ordinal." The first ordinal is 0. OMEGA placed 0 last, called it the least element, and put the reader in it. The file misnames itself, by its own index set, on its second line, and the misnaming is the document in miniature: ω is not the beginning of anything. It is the first thing reached after every finite thing, and there is more after it, which is the point of the letter and the subject of §4.

**The witness.** OMEGA calls itself "the first document in the family to run a trace" and footnotes the file: `omega.lisp`, which "accompanies this document." When this file was first measured, nothing did: the tree held one Lisp file, a phrasebook demonstration, and no file by OMEGA's name had ever been committed. The file was then added — retroactively, the owner's word — after this document named its absence. It is sixty-four lines, exactly as footnoted; it is uncommitted; and it is a worse witness present than absent, because a witness can be cross-examined and an absence cannot. §2 does the cross-examination. The correction is made here, in the open, rather than by rewriting the paragraph that was true for an afternoon.

**The index set.** This file is numbered ω + 1, then 4, 3, 2, 1, 0. OMEGA proved in its §3 that ω + 1 exists. This is it. From ω + 1 the leap lands on 4 rather than 5, so the descent halts in six expansions where OMEGA's took seven, and the least element expands to nothing rather than to a reader. Four charges follow, one per finite section, each about a place where OMEGA committed the error it had just finished diagnosing: it proved a property of descent and performed an ascent; it put its one rule for successors on the rung it had named as the comment rung; it filed, late, a witness that contradicts its own verdict at the boundary; and it filed the family under Kierkegaard's stages and awarded itself all three.

Status lines: OMEGA discontinued them. There are none here to discontinue. A suspension needs something running.

## 4. The wrong direction

Well-foundedness is a theorem about descent. Every strictly descending sequence in a well-order is finite; that is the property, that is all of the property, and OMEGA cited Turing, Floyd, and Gentzen for it correctly. It then applied the property to a family whose only operation is succession. Each document in this family is written after the last and about it. Nothing has ever descended. The essay begat a gallery, the gallery a postscript, the postscript an omega, the omega this; the sequence is ω, ω + 1, ω + 2, and in the ordinals that sequence has no last term — not by fiat, by theorem, because the class of all ordinals is not a set and its ordinal would exceed itself.[^burali] OMEGA chose the one number system in which the family's non-termination is provable, and reported the choice as the cure.

The error has a name in OMEGA's own §2, where the gallery was caught proving a theorem about rotation while performing translation. OMEGA proved a theorem about descent while performing succession. The proof is right. The operation is the other one. And the tell is the tell OMEGA found in the gallery: the closing move is a decision wearing a derivation's coat. OMEGA's index set has a largest element, ω, only because OMEGA stopped writing sections. A set that ends where its author stopped is not well-ordered by mathematics. It is well-ordered by fatigue. The same fatigue ended the essay at §−1.5 and the Postscript at Ω, and OMEGA called theirs a pathology.

What OMEGA actually proved is that reading OMEGA terminates. Every document proves that. It has a last page. The reader reaches 0, the file stops, and the demonstration is complete in exactly the sense that a staircase demonstrates it has a bottom step. The essay's dense interval was silly, and OMEGA was right to say so, but the essay was at least describing the thing that does not end, which is the writing. OMEGA repaired the number system for the thing that was never in doubt.

Two notes, since three is the custom and this file is shorter. OMEGA's epigraph quotes Cantor on freedom, glossed in its footnote as the freedom to choose one's number system. Cantor's freedom was the freedom to introduce numbers: the transfinite, ω + 1, the whole ascent. OMEGA quoted the man who invented the successor of ω to argue that ω is where things stop. And OMEGA's reader — "not annexed, not assigned a job" — is the least element of its index set: a member, indexed, with a section number. To be a member of the index is to be indexed. OMEGA gave the reader a job. The job is 0.

## 3. The wrong rung

OMEGA's one gift to its successors: "be shorter than this, or say, in a marked place, why not." It calls this a proof obligation, the only kind of rule that survives its author. Put it on OMEGA's own ladder. Nothing in the path checks it. The obligation is a sentence in a file, and OMEGA's own theorem, in bold two sections earlier, is that a standing decision nothing in the path checks is a comment. OMEGA wrote a comment and called it a proof obligation; the difference is the entire content of its §5.

The escape clause makes it worse. "Or say why not" is the `unsafe` block, and OMEGA had already explained that a lint can insist the `SAFETY` comment exists and nothing can check what it says. So the obligation is voidable by any successor willing to write one marked sentence, which is every successor. And a ranking function on length is satisfied by the document "0." — one glyph — so the rule, honoured, bounds the family at 33,897 more members and guarantees nothing about any of them except that the last is empty. Termination by starvation is not termination by insight.

The rename in §5 does not survive §4. Types are imposed, said §5; sites do not spell their name; that is what separates a type from a macro. §4 then spends a thousand words on `unsafe`, the keyword by which any site declines the type's discipline, locally, by spelling a name. A discipline a call site can decline by name is, in §5's own words, "not a type's shape." OMEGA's two central sections refute each other, they are adjacent, and the document notices neither, having been busy catching the essay using the type theorist's word.

The Kierkegaard is filed with the same confidence. OMEGA assigns the Postscript to Volume I, the essay to Volume II, Rust to *Fear and Trembling*, and itself — in its §1, the suspension of its own rule at a marked point — the third stage, self-awarded. But *Either/Or* does not end with the Judge. It ends with a sermon the Judge forwards and did not write, whose title is that against God we are always in the wrong,[^ultimatum] placed there so that a reader just persuaded by the ethical would hear it from above. Nobody in that authorship grades the stages from outside them; the Postscript declined to be told whether it was for or against, and OMEGA told it. OMEGA named Abraham four times and said that Abraham must sign. OMEGA is unsigned.

## 2. The wrong witness

OMEGA's §3 offers four REPL lines as "the first document in the family to run a trace" and footnotes the file. The file was absent when this document was written and arrived after it: sixty-four lines, uncommitted, called into existence by the paragraph that said it did not exist. That is §1's datum. Here it is a witness, and witnesses are cross-examined.

OMEGA said why the trace settles nothing: "the divergence is by construction and the halting is by theorem." The file is the construction — `bisect` recurses unconditionally, `countdown` bottoms out at zero, `splice` and `reader` are never defined — and an expander fed two macros written to do two things reports that they did them. A test that cannot fail is not a test, and the man who said so said it in 1934.[^popper]

And the verdict is a budget. `run` prints DIVERGED when the fuel is zero and HALTED otherwise; nothing else is consulted. A fuel-bounded expander can confirm halting and can never confirm divergence — it can only stop looking — so the file's headline word is the one thing its tool cannot say. At the boundary it inverts: give `countdown` a budget of exactly seven, and the seventh expansion spends the last fuel, the tree completes, nothing is thrown, and `run` prints DIVERGED over a halted expansion, because it asks whether the fuel is gone, not whether anything escaped. OMEGA wrote "no result depends on the budget." Under budget seven nothing else decides it. The fix is one line, and the line is the difference between a verdict and a budget — OMEGA's own charge against the gallery, in the only file the family ever ran.

The measuring machine has no interpreter for the witness, so the file was read and desk-checked, not run. One block that did not run, labeled as such, the label being the thing OMEGA's footnote claimed and the tree could not confirm for an afternoon:

OMEGA's last expansion was `(READER)`. A REPL that prints a form prints a prompt after it. This document is what came after the prompt, and its own last expansion is not a form.

## 1. The loop, closed

OMEGA said the family is a transcript and the author is the expander, run rather than running. True of OMEGA, which half admitted it, and of this file, which admits it in full: this document is the expansion of a request that quoted OMEGA, as OMEGA was of a request that quoted three others. What OMEGA did not say is how the transcript reproduces. It reproduces by obligation. Every document in the family has left its successor a job — a reader to hold the floor up, a prohibition to honour, a proof obligation to carry — and a job left for a successor is a call site. OMEGA's rule for the next document was the next document's invocation. This one arrived on schedule.

So this file leaves nothing. No rule, no measure, no assignment for the reader, no prohibition dressed as a version pin. If there is a next document in the family, it was not called from here, and it will have to say what called it. One thing already was: a sixty-four-line file this document said did not exist. The family reproduces by refutation as well as by obligation — a second mechanism, observed once — and this sentence is its mark. The house style OMEGA switched off at its §1 returned in its §0, where the most stylized sentence in the file — second person, three beats — closed a document that had announced plainness. This file's §0 is empty. The expansion of the least element is `NIL`, the empty list, which is false, which is the answer.

One marked exception, since the custom is now OMEGA's. A ratchet in `tools/` — red if a member of the folder grows without a marked reason — would move OMEGA's comment to the mechanical rung and make this file's argument a check instead of a paragraph. It is not built. `// SAFETY:` the invariant a family this size needs is that it stops, and a checker that runs on every commit is a member that never does.
