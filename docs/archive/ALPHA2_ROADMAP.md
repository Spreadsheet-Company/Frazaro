# ALPHA 2 ROADMAP — Frazaro / VLA English

*Opened at the close of Alpha 1's build phases (A–C complete, D1 shipped). This file has two halves: the **carried work** from Alpha 1 (D2 onward, IDs preserved so passes can still be requested by them), and a **five-perspective deep audit** of the whole project — VBA developer, Lisp developer, grammar developer, lay spreadsheet user, and venture capitalist — each with 3–5 criticisms and suggestions, recorded as intake items (V·, L·, G·, U·, M·). Audit items are deliberately un-prioritized: the E3 pilot's parse-failure corpus is the input that ranks them, and the standing override still applies — a real user's breakage outranks any line of this document. Where an audit item lands on an existing carried item, it cross-references rather than duplicates.*

### Audit II — The Lisp developer ("the parenthesis payoff is underdrawn")

**✅ L0. VLA is a first-class citizen of the sheet.** *(Owner proposal; accepted, strengthened, shipped as L0.0 — pending on-machine verification, expected self-test +6 = 161, VerifyReport +1 = H1:H25, vocab unchanged.)* A Frazaro row that *begins* with `(` is a raw VLA form: captured by the tokenizer as one token (balanced within the row, honoring VLA's strings and `;` comments so an inner `)` never miscounts), legal wherever a sentence stands — top level, block bodies, action bodies. `(` anywhere else stays a stray character, now with a teaching hint; `#` comment lines keep parentheses as prose. The strengthening is **check-before-run parity**: each raw row is probe-transpiled at Check inside a scratch Sub, so reader, macro-expander, and emitter errors all land red on the row with line attribution — and top-level heads (`sub`, `defmacro`, `type`…) are refused with directions rather than emitting as garbage calls. Step tracking wraps raw rows like sentences (runtime failures name the row); A4 claims headline them ("a raw VLA form"); D1's qualified-reference Undo scan already covers references inside raw text. **Scope decision, recorded:** one form per row/cell — the owner's own framing — because the progressive Check would false-red the interior rows of a multi-row form; multi-row forms are explicitly gated on V1's translate-once rework. A trailing period or `;` comment on the row is politely consumed. This is also a down-payment on L2: the sheet itself is now a VLA scratchpad. **Maiden-run incident (→ tests L0.1):** the malformed-form pin first used `(if x)`, assuming the emitter refuses a clause-less If — it doesn't, correctly: that emits a vacuous legal `If x Then / End If`, the 1:1 doctrine holding firm against its own test author. Re-pinned with `(set! x)` (a genuinely malformed form, missing its value), which the emitter's own arity error turns red at Check.
