## Proposed — awaiting the owner's adoption call *(recorded here per protocol; none is an item until the owner says so)*

### V-series: production-critical VBA performance, missed by V1–V5 *(all gated on V6's before-numbers — measure first, the standing discipline)*

- **V7 — first-token rule dispatch.** The matcher tries every rule per sentence, and rule storage is `Collection` (indexed access is a linked-list walk, so the scan is effectively O(rules²·sentences) in access cost). Bucket rules by first *matchable* token (literal, alternation branches expanded, or "slot-first") into a keyed index rebuilt at load; sentence dispatch jumps to its bucket. **This is Alpha 3 item 27's own deferred work, given its design early so the promotion is a switch-flip when V6's dial says go** — the day a 1,000-rule org phrasebook exists, Check latency is the product's first impression.
- **V8 — the string-building pass.** `EnglishToVla`, `VlaTranspile`, and the loaders all grow output via `r = r & …` — VBA's classic O(n²) reallocation, invisible at 100 sentences and dominant at 5,000 (exactly the D3/pilot program sizes and F2's LLM-drafted volumes). A pre-sized buffer builder (`Mid$`-assignment with doubling) behind two tiny helpers, plus the same pass's checklist items: cache `VlaHelperManifest` per resolve session instead of per call; early-bind or cache the ADODB stream in `VocabReadFile`; audit `CollGet`'s error-trap cost on hot per-token paths. Behavior-invariant by construction — the goldens are the witness, V6 is the proof of gain.

### L-series: day-1 Lisp features outside L1–L15 *(each already run through L5's four-question test before proposing)*

- **L16 — the small-verbs prelude batch.** `(swap! a b tmp)` (the classic, temporary as parameter), `(dec! x)` (`inc!`'s twin), `(returning tmp expr body…)` (CL's `prog1`, temporary as parameter). All pass all four questions; all golden through `VlaExpand`; a half-pass bundled with any L-band item.
- **L17 — defmacro docstrings.** `(defmacro (f x) "doc" body…)` — one reader/DefineMacro tweak (skip a leading string in the template position, store it), surfaced by L11's `(doc …)` and Explain's macro panel. The one engine-touching proposal here, and the smallest.
- **Adjudicated refusals, recorded so day-1 Lispers get answers, not silence:** *quasiquote/unquote* — unquote is evaluation at expansion time, question four, refused (templates with named parameters are this project's quasiquote); *variadic short-circuit `(and …)`/`(or …)` statement chains* — building a nested-If ladder per argument is per-element iteration, question two, refused (VBA's non-short-circuit `And` is a recorded hazard, handled today by nested `(if …)`, and a fixed-arity `(when-both a b …)` template remains writable by anyone who wants it, in their own phrasebook, via L4); *`let*` over N bindings* — pairwise iteration, question two, refused (nest `let-one`, which composes).

### G-series: business-frequent grammar features, from the day-1 grammarian's chair *(each shaped for the audition-then-adopt loop G5 enables; G9 deliberately priced by pilot evidence)*

- **G6 — list-valued slots.** `{r:cell+}` matching an enumeration — "Make cells A1, B2, and C3 bold." The single most business-frequent shape missing, and *legal*: rule templates cannot iterate (L5), but the **translator** is a program generator, not a template — it can substitute the template once per matched item and emit the results in one `(begin …)`, exactly as structural forms already emit many statements. Comma/`and` list grammar at the tokenizer's existing article discipline; the expanded-signature audit treats `+` as its own shape class; typed validation (G2) applies per item. *Every* "…cells X, Y and Z" near-miss in the future log lands here.
- **G7 — slot defaults.** `{n:expr=1}` — an omissible slot whose default text substitutes when absent ("Insert a row." meaning row 1). Pure substitution, G1's optional-literal machinery generalized from literals to slots; the audit expands present/absent like optionals today.
- **G8 — number words and ordinals.** "Repeat five times.", "Delete the third row." — a bounded token-mapping table (one…twenty, first…twentieth → digits) at the tokenizer, function-word-style and vocabulary-visible so dialects can localize it. Cheap, high-frequency, zero ambiguity in the bounded range; beyond twenty stays digits by doctrine.
- **G9 — conjoined predicates.** "Make cell A1 bold and italic." — real coordination, the hardest and most-requested shape in every English-to-command system. **Proposed as deferred-with-instrument:** the near-miss log and U5's button are precisely the tools that will price it with pilot evidence; a scoped version (same-verb same-target property conjunction only) is the likely adoptable core, and anything broader risks the ambiguity classes ("and" as sequencing vs. conjunction) the percent-blend veto exists to keep out. Recorded now so the pilot's log is read with this item in mind.
- **Answered without an item:** plural/singular surfaces — G1.1 already covers them (`{w:cell/s|range/s}` is legal today; a documentation line in the vocab header, not a feature); anaphora ("Make *it* bold") — **vetoed with reasons**: an antecedent is hidden state, and every sentence in this product means the same thing wherever it stands — auditability (Rehearse, Explain, the goldens) depends on exactly that property; the explicit spelling ("Make that cell bold" naming the cell) costs one reference and keeps every layer honest.
