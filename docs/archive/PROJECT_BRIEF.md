## What this project is

Frazaro ("a phrasebook for your workbook") lets non-programmers automate Excel by writing checked English sentences. Three layers: an **English grammar** (structural forms + phrase rules loaded from `.vocab` phrasebooks; slots are written in braces — `{r:text}` in patterns, `{r}` in templates (G0), and a sheet row beginning with `(` is a raw VLA form, probe-validated at Check (L0)) translates sentences to **VLA** (s-expression VBA, 1:1 semantics, template macros only — "VBA wearing parentheses"; never smooth VBA semantics, that's the compiler trapdoor we always decline), which transpiles to **VBA** injected into the user's workbook. A worksheet IDE (the **Frazaro** sheet — legacy "English" sheets migrate in place when they carry the workspace buttons; vertical Title-Case button stack: Check Sentences / Run Sentences / Undo Last Run / Reload Sentences / Known Sentences / Copy Feedback) provides check-before-run, exact-row red errors, snapshots/undo, Word-file import (via the VLA English menu or first-click Reload), parse-failure logging, and a Phrases sheet whose listing opens with the structural sentence shapes (gated by a self-test). Ships as a locked `.xlam` built by `VlaBuildAddin`, which audits the phrasebook and refuses defective builds.

## The language after Phase B (what a sentence can say)

Core control flow: one-line and block `If` with `Otherwise, if …:` chains; `When <value> is <case>: … When it is <case>: … Otherwise: …` (or-joined cases); `Try: … If that fails: …` (recovery optional; inside it `the problem` is Err.Description, captured before the Resume hop); `Repeat n times` / `Repeat until <cond>` / `While` / `Count … [down] from … to …` / `For each`; `Stop the loop.` / `Stop.` / `Done.`. Data: `Create a number/text/value/list called x.`; `Append … to <list>.`; `count of` / `first of` / `last of` / `item <n> of` (lists and ranges, via the `VlaCount`/`VlaItem` helper family); `value in column …` / `value in cell B2` as honest synonyms for cell reads; `cell in column number <expr> row <expr>` composes in expressions (row expression is greedy: `row 2 plus 1` is row 3). Value actions: unary `To tax of amount: … Give back …`; named/defaulted `To [get] tax using income of 1000 and rate of 15%:` called as `tax using income of 800` (parameter lookahead keeps argument-`and` and condition-`and` untangled; unknown/missing/duplicate parameters and required-after-optional refused at Check, line-attributed); nullary `To get vat-rate: Give back 20%.` (name alone is then a value). Keyed memory (V3, owner-revised): `Create a lookup called prices.`; `Store <v> at key <k> in <lookup>.` (also `under`); `prices for <key>` composes anywhere (loud miss naming the key; scoped to declared lookups so `for` stays inert elsewhere; key binds tight like `length of`); `keys of` walks keys; `For each pair in prices:` walks entries with `key of pair` / `value of pair` (engine-seeded). All user words are program-scoped. Arithmetic: `%` and the word `percent` are a primary-level postfix (÷100, Excel's reading, binds tighter than `times`); `Grow`/`Shrink … by …` are the multiplicative verbs, and (B7.4, owner revision) a **simple `%` share** after `Increase`/`Decrease`/`Add` means the same growth — the idiomatic spelling emits Grow/Shrink's exact template — while a `%` blended into longer arithmetic (`5 plus 5%`, `10% times 2`) refuses loudly, harder than B7, which let the second shape fall through additively. Quoting (the completed liberation): references are bare exactly as formulas write them — `cell B2`, `range A1:C50`, `Data!B2`, `'Q1 Data'!A1:B10` (word-flanked `!` is the sheet qualifier; free-standing `!` still ends a sentence; the apostrophe form is complete-or-refuse, so contractions stay loud) — double quotes are for text values (`""` doubling embeds a quote) and pathological names. Stray characters refuse with formula-habit hints (`+` → "write 'plus'"); curly quotes normalize in the tokenizer. L0: a row that *begins* with `(` is a raw VLA form — one form per row, parens are the terminator, probe-transpiled at Check, step-attributed at Run; `(` anywhere else stays a stray character with a teaching hint. **The authoring surface after Band 1 (G-line):** patterns carry alternations and optionals — **braces capture** (`{d:left|right}` binds the matched word into the template, `xl{d}` → `xlleft`), **bare just matches** (`into|in`, binding nothing; G10), `[key]` optionals (alternations allowed inside), and `stem/suffix` surfaces on either (`center/ed`, stem binds; G1.1); typed reference slots `:range :cell :column :sheet :color` shape-check at Check with teaching refusals, quoted references always asserting past the check (G2); `override:` replaces exactly one earlier same-shape rule with provenance recorded and Explain naming which file won (G3; built-ins not overridable); `fail:` proofs pin refusals and their wording at load (G4); `macro:` carries defmacros — probe-validated, name-collision-refusing, APPENDED to translations (source-map neutral, L4.2) — and the template face hides the dot behind carried functors (`set-formula`, `make-{d}` via English-layer name substitution; G11); `EnglishTryRule` auditions a candidate rule with a shadow verdict and full restoration (G5). The prelude gained `let-one`/`let-one-as`/`if-not`/`while-not`/`(comment …)` (L3); the template limits, idioms, approved future shape, and the four-question "can this be a template?" test are published in VLA_GUIDE with sentinel pins (L5). Dev rig: `VlaTry` (scratch eval, L2) and `VlaTimeIt` (the four-dial timing harness with Name-persisted before/after readings, V6 — Run leg targets the ACTIVE workbook with an Output-sheet pre-flight).

## Collaboration protocol

The assistant writes all VBA **blind** (no Excel available); the human is the compiler, runtime, and QA lab — this asymmetry has produced ~20 bugs caught only by compilation, self-test maiden runs, or clicking, so: never claim code works, only that it should; after every pass instruct: `VlaDevReload` → **Debug → Compile** → `VlaSelfTest` → (if runtime-relevant) reload vocabulary + Run `instructions.txt` → `VerifyReport` → **`VlaWriteGoldens` + `git diff` on the goldens (S1): an empty diff is the behavior-preservation witness; a golden change is a contract change and says so in its commit**. **Diagnostic-first rule (S5's parting lesson, three blind fixes deep):** when a "trivial" fix fails twice, STOP PATCHING — the model of the machine is wrong somewhere upstream; ask for Immediate-window readouts of the actual state and the actual click route before writing a third guard. **Disk-truth check (S5.4):** an uploaded file may carry a PARTIAL prior implementation (S5.3 arrived half-built with a compile error); read what exists before writing what was asked, and remember that a module which fails to compile silently leaves the OLD behavior running — every mystery symptom is suspect until Debug → Compile passes. State expected test counts as *deltas from the printed baseline* (the printout is the authority; remembered counts have been wrong). Bug reports arrive best as the `VlaSelfTest` printout or a `VlaDiagnostics` paste plus the exact message. Passes are requested by roadmap ID; the assistant implements, then explains purpose/benefits, then suggests next steps. **Checkmarks are granted ONLY by the owner's explicit word** (protocol correction, Audit-I session): the assistant records passes as "shipped — awaiting owner verification and sign-off," never ✅ in any form, until told; the owner's "mark X complete" is the sole trigger. Owner aesthetic proposals arrive with an explicit invitation to veto on implementation grounds — the assistant vetoes with reasons (`!`-as-comment, `;`-as-comment) or accepts and often strengthens (`!` sheet refs, `'…'!` spaced sheets, `%`, `value in`, `using`); either way the reasoning is recorded on the roadmap, not left in chat. **The standing override: a real user's breakage outranks any roadmap line.** Version control (M5a): the project folder is a git repository; one pass = one commit with the pass ID in the message; the human tags each on-machine-verified state (`<pass-id>-verified`); `git diff` after applying the assistant's files is the mechanical check on blind edits (an empty diff means no change arrived — the presentation-discipline alarm), and `git restore .` is the instant path back to the last good state. **Reload discipline (Audit I):** when a pass adds a module, update `VLA_DevRig.bas`'s reload list by hand FIRST, then run one `VlaDevReload` — never hand-import a module the list covers (the VBE silently mints `Name1` duplicates); after any messy session, `VlaAuditDuplicates` before compiling. **Topology discipline:** the dev workbook masks cross-project failures by construction (everything one project); any feature touching what ships into USER workbooks must be verified in the standalone topology — dev workbook closed, fresh workbook, built add-in — which is now the D3 script's headline scenario; **and "a prior standalone test covered this call" is not coverage: stateless linkage proving is not stateful sharing proving** (S5.6 — the trace armed the add-in's seam instance while the run consulted the injected copy's; any seam feature that carries STATE re-earns its own standalone check). **Credit discipline:** attach only the files the requested pass touches (per the attach-lists below); reference unchanged files by their git tag instead of attaching; one pass per turn. `GIT_WORKFLOW.md` is the one-page reference; the `.xlam` build artifact is ignored, the dev `.xlsm` and all text sources are tracked.

## Standing disciplines (all earned by specific incidents; violate none)

1. **Every rule ships with a `test:` line** — vocabularies refuse to load on failing proofs (currently 181 tests). Block-form structural grammar can't carry vocab tests until D2's marker-free test translation; its proofs live in the rig.
2. **Grep the phrasebook before writing a rule; run `EnglishAuditPhrasebook` after any batch** — first-full-match means unknown duplicates silently win.
3. **Present every file a pass touches**, even one-line diffs — an unpresented change is indistinguishable from no change — and **never narrate a presentation that didn't happen** (violated in this form once: a fix was described as "re-presented above" with no file attached; worse than forgetting, because it reads as done). Since M5a, `git diff` after applying a pass is the mechanical witness: an empty diff means no change arrived.
4. **After bulk text edits, grep for survivors — to exhaustion** (a `head`-truncated grep hid B7.4's fifth pin); anchored replacements miss indented cases; caption and sheet-name renames sweep messages *and* docs; and **messages that talk about old syntax are exempt from syntax migrations** (G0's sweep rewrote its own teaching refusal).
5. **Soft-failure doctrine:** auxiliary machinery (snapshots, logging, menus, legacy-sheet migration) fails *softer* than what it assists.
6. **Verb audition:** every form judged by the typist's expectation (Set=name, Put=place, Remember=keep-object, Define=permanence, Show/Say=box, Log=Immediate; cell=the place, value=what's in it; Grow/Shrink=multiplicative, Increase/Add=additive for plain amounts while a simple `%` share means growth — the mechanism follows the amount's shape, B7.4; `get` marks value-returning-ness). One verb never means two mechanisms; synonyms (Show/Say, %/percent, of-form/using-form, Increase-with-share/Grow) are fine.
7. **Error voice:** first-person tool, jargon-free, names what the user can see, every user-reachable failure names its sentence and line; refusals teach the correct spelling (stray-char hints, percent-hazard guidance, standalone-Get pointer). "Sentence" is the domain term.
8. **Safety defaults:** nothing irreversible unwatched; loud-never-silent for ambiguity with a dangerous branch (thousands comma, percent-hazard, complete-or-refuse apostrophe); the program sheet is protected during runs.
9. **Bugs become permanent regressions** — a `test:` line, a self-test assertion, or an annotated sentence in `instructions.txt` (click-free: Log, never Show), with the incident cited in place. **When pinning a refusal, first prove the refusal exists** (L0's `(if x)` pin asserted a strictness the 1:1 doctrine correctly forbids). Compile-structure bugs (declaration placement, typed-argument mismatches) are pinned by the compile gate itself — no test can express them.
10. **Version constants** bump on every module edit and **track pass IDs, not chronology** (current: VLA core **S3.1**, VLA_English **S5.0**, VLA_Runtime **S5.2**, VLA_IDE **S5.5**, VLA_Build **S5.4**, VLA_Tests **S5.5**, VLA_DevRig **V5.3**); `VlaDiagnostics` prints them.
11. **VBA hazards to remember:** no short-circuit And (predicates total); Set vs Let — *and the hazard you absorb reappears one call-frame down*: `CollGet` branches on IsObject, `CollHasKey` must probe via `IsObject(col.Item(k))` not a Let-copy, `VlaItem`/`VlaFirst`/`VlaLast` branch per item (three strikes in one pass); reserved words (`Get` refused its own author's test); Optional parameters must come last (guarded at Check for both `with` and `using`); Optional defaults must be constant expressions (`(15 / 100)` qualifies); ParamArray can't be forwarded; lazy compile hides undefined names (hence the compile gate); module removal is deferred; very-hidden sheets can't Copy; ActiveSheet binds unqualified Range/Cells — but Application-level `Range("Data!B2")` with qualified strings bypasses it; errors raised inside an active handler are untrappable (Try's `Resume` hop exists for this — and C1's `with-fast-excel` recruits it: the restore-then-re-raise cannot be re-trapped locally, which IS the guarantee); step instrumentation must emit `Exit Function` in Functions; **a Variant cannot ride into a typed ByRef parameter** — `Set` into a typed local first (the typed hop; C2.1's maiden compile); **module-level declarations precede the first procedure, always** (D1.1); Optional object parameters take no spelled default — omission is `Nothing`; **Compile On Demand (the default everywhere) compiles per PROCEDURE, not per module** — a sacrificial call verifies nothing beyond itself, and **compile errors cross `Application.Run` as untrappable MODALS**, so no in-VBA probe design can ever intercept them (S4's empirical verdict — the whole solution family is dead; static checks on generated text are the road); **modifying a running project's code resets its module-level variables** (project state loss — the Run wipes any flag stored beside it; workbook `Names` survive recompiles, but two topologies mean two `ThisWorkbook`s, so the real fix is designs that arm-run-read in ONE call chain, never state across a boundary — S5's whole arc); **`ObjPtr` keys are recycled memory addresses** — an absent key lets a new object read a dead object's entry, heap-dependently (phantom map tags, S3.1); "deliberately no value" must be an EXPLICIT stored zero, never an absent key; **customUI ribbon labels are XML** — a raw `&` silently drops the whole ribbon by soft-failure (`RibbonBtn` does not escape; prefer ampersand-free labels); and one blind-writing self-check now mechanized on the assistant's side: **sweep for statements welded onto signature lines and for module-level declarations below a file's first procedure** before presenting (S5.4's welded `Dim` failed a whole module's compile and masked three other symptoms behind old code). **Band-1 additions:** this engine's defmacro is `(defmacro (name params…) body)` — name INSIDE the signature list, and the wrong dialect has now bitten three times (read the prelude, not memory); a bare `Function` call in the Immediate window prints nothing (`?` prefix prints; the parse-failure message teaches it); unqualified Immediate-window names resolve only in the ACTIVE project — cross-project use `Application.Run "Frazaro.xlam!Name"`; anything textual carried into every translation must APPEND, never prepend — prepending shifts every `' vla:N` source-map tag (L4.2's owner-caught golden diff); an `EnglishResetGrammar` inside a test section is a FENCE — everything depending on earlier registrations runs before it (G1.3); a harness needing ambient context it cannot know gets a stated requirement plus a zero-cost refusal, never a guess (V6.1→V6.2, two incidents); and no bare engine call in a suite section — a raise aborts every section after it; ride the `TryTranspile`/`TryEnglish` guards (L2.1/L2.2).
12. Modules are self-contained: duplicate small helpers rather than share Privates cross-module.
