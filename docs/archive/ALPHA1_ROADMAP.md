# Alpha 1 — Master Roadmap

*Consolidates every outstanding item from all prior planning into one sequence. "Alpha 1" is the release we hand to pilot users; the version number closes when the owner says so, not before. Standing disciplines apply to every pass: `test:` lines for every rule, Debug → Compile after every re-import, the duplicate-signature audit after every rule batch, `english.txt` stays click-free and gains a probe per feature, bugs become permanent regressions.*

## Phase B — Language completeness (the day-1 grammar debt)

**✅ B1. The `(new …)` form + lists.** *(shipped; verified on-machine — compile clean, self-test +7, vocab tests +5, VerifyReport +1 (H7))* One VLA expression case (`(new Collection)` → `New Collection`) — found already present in the emitter, now golden-pinned — then the English: `Create a list called found-items.`, `Append ?e:expr to ?v:var.` (verb chosen to dodge arithmetic `add`; slot is `:var`, not `:name`, so appending to a never-created list fails as a step-numbered runtime message rather than a VBA compile error), `count of` via the function-word registry (built-in, backed by the polymorphic `VlaCount`), `For each x in found-items:` (worked once lists existed). *Done when:* a program collects matching rows into a list and walks it. ✓

**✅ B2. Branching completeness.** *(shipped; verified on-machine — compile clean, self-test +8, vocab tests +2, VerifyReport +3 (H8:H10))* `Otherwise, if <cond>:` chains (block and one-line branches, via the generalized `ParseBranchBlock`/`ContinuationAhead` machinery); `When <value> is <case>: … When it is <case>: …` as English Select Case, with `or`-joined values sharing a case and `Otherwise:` as the catch-all; `Repeat until <condition>:` over VLA `do-until`, feeding the loop-kind stack as "do". *Done when:* a three-way regional branch reads as three paragraphs, not nested ifs. ✓

**✅ B3. Error tolerance.** *(shipped; verified on-machine — compile clean, self-test +6 (+1 listing gate), VerifyReport +2 (H11:H12))* `Try:` … `If that fails:` … blocks over VLA's `on-error` — resilience, not just reporting, for programs touching locked files and missing sheets. The step-tracking interaction designed deliberately: step numbers advance through the body; body failures jump silently via `Resume` out of handler-active state (VBA cannot trap an error raised inside an active handler); recovery runs under the restored step handler so its own failures report normally; both exits re-arm the surrounding handler (`On Error GoTo 0` when tracking is off). Recovery paragraph optional. *Done when:* a program survives a missing file and says so politely. ✓

**✅ B4. Value-returning actions.** *(shipped; verified on-machine — compile clean, self-test +9, VerifyReport +2 (H13:H14))* `To tax of amount: … Give back amount times 0.08.` → a `Function`; the name registers as a unary function word before the body parses (recursion composes), so `tax of subtotal` works everywhere, conditions included. User words are program-scoped (unregistered at the next translation). `Give back` is structural and refuses itself outside a function; bare `Stop.` and the step epilogue emit `Exit Function` in function context; `CheckDupAction` refuses duplicate action names and built-in-word shadowing (closing the pre-existing duplicate-Sub compile-crash hole), line-attributed. One parameter, `Variant` return — multi-parameter goes to B6. *Done when:* a user-defined calculation appears inside a condition. ✓

**✅ B5. Expression loose ends.** *(shipped; verified on-machine across B5.1-B5.3 — compile clean, self-test at 87/87, vocab 172, VerifyReport through H18)* The prim's `number` branch (computed columns as values; row expression blessed as greedy — `row 2 plus 1` is row 3); `value in column …` / `value in cell B2` synonyms (owner request: cell = the place, value = what's in it); `Ask … and put answer into` blessed as one ask-and-store idiom, rationale recorded in the phrasebook; stray characters refuse loudly with formula-habit hints (`+` → "write 'plus'"), curly quotes normalize in the tokenizer; sheet-qualified refs REVERSED then EXTENDED by owner decisions — bare `Data!B2` via word-flanked-`!` adjacency, bare `'Q1 Data'!A1` via complete-or-refuse apostrophe scan, double-quoted form kept as escape hatch. ✓

**✅ B6. Multi-parameter value-returning actions.** *(shipped; verified on-machine across B6.1-B6.3 — compile clean, self-test 102/102, vocab 173, VerifyReport through H20)* Named parameters via `using` (owner design): `To [get] tax using income of 1000 and rate of 15%:` — `of` gives a default (idiom reused from `with`-clauses), `get` optional sugar at both sites, calls compose as expressions with VBA named arguments filling omitted defaults, zero emitter changes. The `and`-collision resolved by parameter lookahead. Guards (all line-pinned): unknown/duplicate/missing-required parameters at Check; required-after-optional at definition, retrofitted to `with`-clauses; parameter-shadows-function-word. ## Phase E — Market preparation

**⬜ E1. Naming decision.** Pick the consumer name (Longhand et al.); VLA stays as the engine name; `.vocab` files become **phrasebooks** in every doc and menu string; trademark/domain checks. Optionally A/B the two finalists on pilot users and keep whichever they say unprompted. *(Partially pre-empted by owner decision, B3-era: the IDE workspace tab is already renamed **Frazaro**, with in-place migration of legacy "English" sheets — the button-bearing sheet is renamed, program text riding along.)* Also decide **comment syntax** here, with pilot parse-failure evidence: `#` (status quo; weak/neutral civilian semantics, safe anywhere-in-line because nobody types it mid-sentence) vs `[bracketed asides]` (Inform 7 precedent; aside-semantics match comments, multi-line for free, unclosed bracket errors loudly) vs `Note:` paragraphs (comments as English; needs deliberate tokenizer design around quotes). Explored and vetoed B3-era: `!` (semantics invert — "look here" marking "ignore this" makes silent non-execution of emphasized lines; `!!` blocks collide with natural typography and break the IDE's per-row legibility) and `;` (mid-sentence semicolon is natural prose AND programmer statement-separator, so anywhere-in-line comments silently discard half a sentence; ergonomic gain reverses on non-US layouts; more programmer-coded than `#` by the audience's own audition — though it would match VLA's own `;` comments one layer down).

**⬜ E2. First-contact polish.** "New program" button seeding a commented working example; multi-phrasebook config for `IdeVocabPath` (load `scripts\*.vocab` in name order); starter phrasebooks for one or two verticals if a pilot user's domain suggests them.

**⬜ E3. The pilot.** Three to five spreadsheet power users found by artifact ("who owns the workbook everyone fears?"); pair-write their most hated weekly task in session one; week-two log review; month-end interview. **Kill criteria pre-committed in writing:** (1) at least one program still clicked after a month of Mondays, (2) at least one user modified a program alone. Both fail → execute the pre-chosen pivot; either passes → their requests re-rank everything below this line.

Interpreter mode.** Executor walking parsed VLA (`ExecStmt`/`EvalExpr` mirroring the emitter, `CallByName` member dispatch, per-call variable frames) — no code generation, no VBProject trust setting, plain `.xlsx` workbooks. Named-arg templates get dedicated handlers; `raw` stays transpiler-only. Ships as a toggle beside the transpiler with a "Show me the VBA" button preserving auditability. *Done when:* `english.txt` produces identical Output sheets under both modes — the dual-mode regression is part of the definition.

**⬜ F2. LLM-draft bridge.** "Describe what you want" → phrase list as prompt → candidate sentences into column A → Check validates deterministically → red rows drive retry. Repositions the product as the review layer for AI-generated automation. *Done when:* a description becomes a green program the user read before running.

**⬜ F3. Distribution hygiene.** Code-signing the add-in; versioned phrasebook releases; a public compatibility note per release.

## Backlog (demand-ordered by the pilot's parse-failure log — do not pre-empt)

- **Tier-2 helpers:** data-validation dropdowns (`VlaDropdown` — predicted first ask), conditional formatting, charts (`VlaMakeChart`), pivots (`VlaMakePivot`), regex, web requests.
- **Events** (`When the sheet changes:` / `When this button is clicked:`): requires VLA Tier 2 (class-module emission, `defprop`); the flagship of the next version, possibly interpreter-simulated earlier.
- **Self-hosting:** port the phrasebook loader to VLA (its tests validate the port); needs C2.
- **Performance:** `Scripting.Dictionary` behind existing helper signatures; first-word indexing for the matcher — deferred until vocabularies triple.
- **Horizon:** localization (grammar is data), macro-recorder-to-English, computed multi-cell range phrasings if demanded.
