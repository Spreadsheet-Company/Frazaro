The appearance fixture (KERNEL.50). Each case sits under a line
"=== <name>" and is the one line after it: a format as the record spells it
after its index, its fill, number format and wrap, then what it says of a
font, an alignment and a border, (font ...) (align ...) (border ...),
written as the record prints it; these lines before the first header are
ignored. A header that ends "!refused <words>" names a format the language
refuses, the words being ones its refusal names (grid-format-property).
VlaWriteAppearanceGolden (VLA_Tests.bas) has Excel apply every case to the
cell beside its name in a workbook it adds, through the object model, and
read it back; saves that workbook beside this file as appearance_saved.xlsx,
Excel's own styles part; opens appearance_written.xlsx beside it, the same
cases as frazaro-core's writer writes them, row for row, and reads its
cells back; and writes appearance_golden.txt: the header, then
"EXCEL<TAB><its own cell read back>" or "EXCEL<TAB>REFUSED <Excel's error
number>", then "WRITTEN<TAB><the written cell read back>", or
"WRITTEN<TAB>REFUSED" for a case the language refuses, each read in the
record's spelling with every property at Excel's default left out.
vla-lang's tests/appearance_golden.rs holds the language to that file over
the crate's copies, frazaro-core's tests hold the writer to it, and
tools/check_appearance_golden.ps1 holds the pair's shape and the properties
the cases reach.
