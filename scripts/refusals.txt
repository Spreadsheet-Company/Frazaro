The refusal fixture (PORT.6, slice 6f). Each case sits under a line
"=== program <name>" or "=== phrasebook <name>" and runs to the next such
line; these lines before the first header are ignored. A program case is an
English program translated by EnglishToVla after english.vla has loaded; a
line of exactly "---" inside it divides a phrasebook text (above, loaded
after english.vla under the case's name) from the program (below). A
phrasebook case is a phrasebook text loaded after english.vla, under the
case's name. VlaWriteRefusalGolden (VLA_Tests.bas) writes the reference's
reading of every case to refusals_golden.txt: the header, then one line
"REFUSED<TAB><line><TAB><id><TAB><text>" (the line is
EnglishLastErrorLine() for a program and "-" for a phrasebook), or
"TRANSLATED" or "LOADED<TAB><n> rules" where the reference does not refuse;
the core (core/src/english/refusals.rs) is held to that file by its own
test. A case is named for the refusal id it is meant to reach; the golden
records what the reference actually says.
